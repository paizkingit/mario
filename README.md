# CODE QUEST — Adventure of the Coder

Game platformer edukasi coding berbasis HTML5 Canvas dan Web Audio API.

## Menjalankan
Buka `index.html` langsung di browser. Tidak membutuhkan server, CDN, atau internet.

## Kontrol
Desktop: A/D atau panah kiri/kanan, Space/W/Atas untuk lompat, E untuk interaksi, Esc untuk pause, R untuk restart.
Mobile: tombol touchscreen.

## Catatan
Audio dibuat secara programmatic melalui Web Audio API setelah interaksi pengguna.
